## 1. Блокова модель (Box Model)

**Кожен** HTML-елемент браузер малює як прямокутник, що складається з чотирьох шарів:

```
┌──────────────────────────────────────────┐
│                 margin                   │  ← зовнішній відступ (прозорий)
│   ┌──────────────────────────────────┐   │
│   │             border               │   │  ← рамка
│   │   ┌──────────────────────────┐   │   │
│   │   │         padding          │   │   │  ← внутрішній відступ (з фоном)
│   │   │   ┌──────────────────┐   │   │   │
│   │   │   │     content      │   │   │   │  ← вміст: width × height
│   │   │   └──────────────────┘   │   │   │
│   │   └──────────────────────────┘   │   │
│   └──────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

| Шар | Властивість | Чи зафарбовується `background`? | Чи входить у розмір елемента? |
|---|---|---|---|
| Вміст | `width`, `height` | ✅ | ✅ |
| Внутрішній відступ | `padding` | ✅ | ✅ |
| Рамка | `border` | (під рамкою) ✅ | ✅ |
| Зовнішній відступ | `margin` | ❌ прозорий | ❌ — лише відштовхує сусідів |

> 🔎 У DevTools → Elements → панель **Computed** (або **Layout**) є інтерактивна схема Box Model обраного елемента з точними числами.

## 2. width та height

```css
.element {
  width: 250px;
  height: 100px;
  background: pink;
}
```

- **Блочний** елемент без `width` займає **всю доступну ширину** батька; без `height` — висоту за вмістом.
- ⚠️ `width` і `height` **не працюють для рядкових** (inline) елементів (`span`, `a`, `b`…). Щоб вони запрацювали — змініть `display` на `block` або `inline-block`.

### Обмеження розміру

| Властивість | Призначення |
|---|---|
| `min-width` / `max-width` | Мінімальна / максимальна ширина |
| `min-height` / `max-height` | Мінімальна / максимальна висота |

```css
.container {
  width: 100%;
  max-width: 1200px; /* на великих екранах не ширше 1200px, на малих — гнучкий */
}
img { max-width: 100%; } /* картинка не вилізе за межі батька */
```

> 💡 **Порада:** уникайте фіксованої `height` для блоків із текстом. Текст може стати довшим (переклад, інший шрифт, збільшення масштабу) — і вилізе за межі. Краще `min-height`.

## 3. Відсотки та «випадання» з батька

**Відсотки** обчислюються від **розміру контентної області батька**:

```css
.parent { width: 200px; height: 200px; }
.child  { width: 50%; }   /* = 100px */
.child  { width: 125%; }  /* = 250px — «випаде» за межі батька */
```

> ⚠️ `height` у відсотках працює, лише якщо **батько має явно задану висоту**. Інакше `height: 50%` ігнорується (бо «50% від auto» обчислити неможливо).

### «Випадання» вмісту

Якщо задати дочірньому елементу ширину більшу, ніж у батька, або батьку висоту меншу, ніж потрібно вмісту — вміст **виходить за межі** (overflow), але батько свої розміри **не змінює**.

> 📄 Приклади: [02_falling_out_from_content.html](examples/02_falling_out_from_content.html), [02.1_falling_out_from_content.html](examples/02.1_falling_out_from_content.html)

## 4. overflow: коли вміст не вміщається

| Значення | Поведінка |
|---|---|
| `visible` (за замовч.) | Вміст виходить за межі й видимий |
| `hidden` | Вміст обрізається, прокрутки немає |
| `scroll` | Вміст обрізається, смуги прокрутки **є завжди** |
| `auto` | Смуги прокрутки з'являються **лише за потреби** ✅ |

Можна керувати осями окремо: `overflow-x`, `overflow-y`.

```css
.table-wrapper { overflow-x: auto; } /* широка таблиця прокручується на мобільних */
```

## 5. padding — внутрішні відступи

Відстань між **вмістом** і **рамкою**. Фон елемента зафарбовує і padding.

```css
.block {
  padding-top: 40px;
  padding-right: 30px;
  padding-bottom: 20px;
  padding-left: 10px;
}
```

### Скорочений запис — «за годинниковою стрілкою» 🕛

| Запис | Означає |
|---|---|
| `padding: 20px;` | усі 4 сторони — 20px |
| `padding: 10px 20px;` | верх/низ — 10px, право/ліво — 20px |
| `padding: 10px 20px 30px;` | верх — 10, право/ліво — 20, низ — 30 |
| `padding: 10px 20px 30px 40px;` | верх, право, низ, ліво (**TRouBLe**: Top-Right-Bottom-Left) |

```
        top
         ↓
left → [   ] ← right        padding: top right bottom left;
         ↑
       bottom
```

- Від'ємні значення для `padding` **заборонені**.
- Відсотки в `padding` (навіть вертикальному!) рахуються від **ширини** батька.
- У списків `ul`/`ol` браузер за замовчуванням ставить `padding-left` (≈40px) — саме там «живуть» маркери.

> 📄 Приклад: [03_padding.html](examples/03_padding.html)

## 6. border — рамка

```css
/* border: товщина стиль колір; */
.block { border: 10px solid black; }

/* Окремі сторони */
.block {
  border-top: 10px solid red;
  border-bottom: 5px dashed blue;
}
```

| Стиль (`border-style`) | Вигляд |
|---|---|
| `solid` | ───── суцільна |
| `dashed` | – – – штрихова |
| `dotted` | ····· крапкова |
| `double` | ═════ подвійна |
| `none` | немає рамки |

Окремі властивості: `border-width`, `border-style`, `border-color`; кожна підтримує запис на 1–4 значення, як `padding`.

> ⚠️ Без `border-style` рамки **не буде** — навіть якщо задано товщину і колір. Стиль — обов'язкова частина.

> 💡 `button { border: none; }` — частий перший рядок при стилізації кнопок, щоб прибрати стандартну рамку браузера.

> 📄 Приклад: [04_border.html](examples/04_border.html)

## 7. outline — контур

```css
.block { outline: 15px solid blue; }
```

| | `border` | `outline` |
|---|---|---|
| Впливає на розмір елемента | ✅ | ❌ — малюється «поверх», не зсуває сусідів |
| Окремі сторони | ✅ | ❌ — лише всі 4 одразу |
| Заокруглення | ✅ з `border-radius` | ✅ (у сучасних браузерах) |
| Основне призначення | Дизайн | **Індикатор фокусу** (клавіатурна навігація) |

> ⚠️ **Не пишіть `outline: none` для полів і кнопок** без заміни! Користувачі клавіатури перестануть бачити, де фокус. Якщо стандартний вигляд не подобається — стилізуйте:
>
> ```css
> :focus-visible { outline: 3px solid orange; outline-offset: 2px; }
> ```

> 📄 Приклад: [05_outline.html](examples/05_outline.html)

## 8. box-sizing

Це **найважливіша** властивість лекції. Вона визначає, **до чого** застосовуються `width` та `height`.

### `content-box` (за замовчуванням)

`width` — це лише ширина **вмісту**. Padding і border **додаються зверху**:

```css
.block {
  width: 200px;
  padding: 20px;
  border: 7px solid green;
}
/* Реальна ширина = 200 + 20·2 + 7·2 = 254px 😱 */
```

### `border-box` ✅

`width` — це ширина **разом із padding і border**. Вміст стискається, щоб усе вмістилося:

```css
.block {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 7px solid green;
}
/* Реальна ширина = 200px 🎉 (вміст = 200 − 40 − 14 = 146px) */
```

```
content-box:  |7|20|────── 200 ──────|20|7|  = 254px
border-box:   |7|20|────  146  ────|20|7|    = 200px
```

### Рекомендація — додавайте на початок кожного проєкту

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

> 💡 Тепер «колонка 50%» з padding справді займе 50%, а не 50% + відступи. Саме тому `border-box` використовують у всіх сучасних CSS-фреймворках.

> 📄 Приклад: [06_box-sizing.html](examples/06_box-sizing.html)

## Шпаргалка: як порахувати ширину елемента

```
content-box:  загальна ширина = width + padding-left + padding-right + border-left + border-right
border-box:   загальна ширина = width
Місце, яке займає на сторінці = загальна ширина + margin-left + margin-right
```

## Контрольні питання

1. З яких шарів складається блокова модель CSS? Намалюйте схему.
2. Які шари зафарбовує `background`? Який шар завжди прозорий?
3. Чому `width` і `height` не працюють для `<span>`? Як це виправити?
4. Яку ширину має блочний елемент, якщо `width` не вказано? А висоту?
5. Для чого потрібні `min-width`, `max-width`? Наведіть типовий приклад використання `max-width`.
6. Від чого обчислюються відсотки у `width`? А у `padding-top`?
7. Чому `height: 50%` іноді «не працює»?
8. Що відбувається, коли вміст більший за батьківський блок? Які значення має `overflow`?
9. Чим `overflow: scroll` відрізняється від `overflow: auto`?
10. Розшифруйте записи: `padding: 10px`, `padding: 10px 20px`, `padding: 5px 10px 15px 20px`.
11. Чи можна задати від'ємний `padding`?
12. Які три складові має властивість `border`? Яка з них обов'язкова?
13. Чим `outline` відрізняється від `border`? Чому не можна просто прибрати `outline` у кнопок?
14. Порахуйте реальну ширину блоку: `width: 300px; padding: 15px; border: 5px solid;` при `content-box` та при `border-box`.
15. Що робить `box-sizing: border-box` і чому його рекомендують застосовувати до всіх елементів?

2. Зробіть блок-«чат» висотою 200px, у якому багато повідомлень прокручуються вертикально, але не горизонтально.
