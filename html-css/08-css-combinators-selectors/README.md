## 1. Псевдокласи

**Псевдоклас** — додаток до селектора, що вибирає елемент за його **станом** (наведення, фокус, відвіданість) або **позицією в дереві документа**.

```css
selector:pseudo-class { … }   /* пробілів довкола «:» немає! */
a:hover { color: red; }
:hover  { … }                 /* без селектора = *:hover, тобто будь-який елемент */
```

### Псевдокласи стану (взаємодія з користувачем)

| Псевдоклас | Коли спрацьовує |
|---|---|
| `:hover` | Курсор над елементом |
| `:active` | Елемент натиснуто (мишею, доки кнопка затиснута) |
| `:focus` | Елемент у фокусі |
| `:focus-visible` | Фокус, який треба *показати* (зазвичай — з клавіатури) |
| `:visited` | Відвідане посилання |
| `:link` | Ще не відвідане посилання |
| `:checked` | Обраний checkbox/radio |
| `:disabled` / `:enabled` | Вимкнене / увімкнене поле |
| `:valid` / `:invalid` / `:required` | Стан валідації форми |

### Порядок для посилань — **LoVe HAte** ❤️

```css
a:link    { color: blue; }
a:visited { color: purple; }
a:hover   { color: red; }
a:active  { color: orange; }
```

Однакова специфічність → перемагає останній, тому порядок важливий: **L**ink → **V**isited → **H**over → **A**ctive.

```css
.btn {
  background: royalblue;
  transition: background 0.2s;   /* плавна зміна */
}
.btn:hover  { background: darkblue; }
.btn:active { transform: scale(0.97); }
```

## 2. Структурні псевдокласи та nth-child

| Псевдоклас | Вибирає |
|---|---|
| `:first-child` | Перший дочірній елемент свого батька |
| `:last-child` | Останній дочірній |
| `:only-child` | Єдиний дочірній |
| `:nth-child(n)` | За формулою (див. нижче) |
| `:nth-last-child(n)` | Те саме, але рахуючи з кінця |
| `:first-of-type`, `:last-of-type`, `:nth-of-type(n)` | Те саме, але **серед елементів того самого тегу** |
| `:not(selector)` | Усі, **крім** тих, що відповідають селектору |
| `:empty` | Елемент без вмісту |

### Формула `nth-child(an + b)`

`n` пробігає значення 0, 1, 2, 3… Нумерація елементів починається з **1**.

| Запис | Вибирає | Номери |
|---|---|---|
| `:nth-child(3)` | Третій | 3 |
| `:nth-child(odd)` = `2n+1` | Непарні | 1, 3, 5, 7… |
| `:nth-child(even)` = `2n` | Парні | 2, 4, 6, 8… |
| `:nth-child(3n)` | Кожен третій | 3, 6, 9… |
| `:nth-child(n+4)` | Починаючи з четвертого | 4, 5, 6… |
| `:nth-child(-n+3)` | Перші три | 1, 2, 3 |
| `:nth-child(n+2):nth-child(-n+5)` | Діапазон | 2, 3, 4, 5 |

```css
tr:nth-child(even) { background: #f2f2f2; } /* «зебра» для таблиці 🦓 */
li:not(:last-child) { border-bottom: 1px solid #ccc; } /* розділювач між пунктами */
```

### `:first-child` vs `:first-of-type`

```html
<div>
  <h2>Заголовок</h2>
  <p>Абзац 1</p>   <!-- p:first-child ❌ (перший — h2), p:first-of-type ✅ -->
  <p>Абзац 2</p>
</div>
```

> ⚠️ **Типова помилка:** `p:first-child` означає «`p`, **який є** першою дитиною», а не «перший `p`». Якщо першою дитиною є `h2`, правило не спрацює.

> 🎮 Поекспериментуйте з формулами в [nth-child tester](https://css-tricks.com/examples/nth-child-tester/).

> 📄 Приклади: [02_Псевдо класи child.html](<examples/02_Псевдо класи child.html>), [03_Псевдо клас nth-child(№).html](<examples/03_Псевдо клас nth-child(№).html>), [04_Псевдо клас nth-child(№).html](<examples/04_Псевдо клас nth-child(№).html>)

## 3. Універсальний селектор

`*` вибирає **всі** елементи (або всі всередині певного контексту):

```css
* { box-sizing: border-box; }   /* усі елементи сторінки */
.card * { margin: 0; }          /* усі нащадки .card */
```

Специфічність `*` = 0, тому його легко перекрити будь-яким іншим правилом.

## 4. Комбінатори

**Комбінатор** пояснює **зв'язок** між селекторами.

| Комбінатор | Синтаксис | Кого вибирає |
|---|---|---|
| Нащадки | `A B` (пробіл) | Усі `B` всередині `A` на **будь-якій** глибині |
| Дочірні | `A > B` | Лише **прямі діти** `B` елемента `A` |
| Сусідній | `A + B` | `B`, що йде **одразу після** `A` (той самий батько) |
| Загальний родинний | `A ~ B` | **Усі** `B`, що йдуть **після** `A` (той самий батько) |

```html
<ul class="menu">
  <li>Пункт 1</li>
  <li class="active">Пункт 2
    <ul>
      <li>Підпункт</li>
    </ul>
  </li>
  <li>Пункт 3</li>
  <li>Пункт 4</li>
</ul>
```

```css
.menu li      { … } /* усі 5 li, включно з «Підпункт» */
.menu > li    { … } /* лише 4 li верхнього рівня */
.active + li  { … } /* лише «Пункт 3» */
.active ~ li  { … } /* «Пункт 3» і «Пункт 4» */
```

### Візуально

```
.menu
 ├── li            ← .menu > li ✅  .menu li ✅
 ├── li.active     ← .menu > li ✅  .menu li ✅
 │    └── ul
 │         └── li  ← .menu > li ❌  .menu li ✅
 ├── li            ← .active + li ✅  .active ~ li ✅
 └── li            ← .active + li ❌  .active ~ li ✅
```

### Практичні рецепти

```css
/* Відступ між сусідніми картками, але не перед першою — «лобототомована сова» 🦉 */
.card + .card { margin-top: 16px; }

/* Стилізація підпису, що йде одразу після чекбокса */
input:checked + label { text-decoration: line-through; }
```

> 💡 Не будуйте довгих ланцюжків на кшталт `body div.content ul li a span` — це повільно читати, важко перекривати і «ламається» від найменшої зміни HTML. Ідеал — 1–3 рівні.

## 5. Каскад і специфічність — детально

### Порядок пріоритетів каскаду (від найвищого)

1. Користувацькі стилі з `!important`
2. Авторські стилі з `!important`
3. Авторські стилі
4. Користувацькі стилі
5. Стилі браузера за замовчуванням

Після цього правила впорядковуються за **специфічністю**, а за рівної специфічності — **перемагає останнє**.

### Обчислення специфічності: (a, b, c, d)

| Рівень | Що рахуємо |
|---|---|
| **a** | Inline-стиль (`style="…"`) → 1 |
| **b** | Кількість `#id` |
| **c** | Кількість `.class`, `[attr]`, `:pseudo-class` |
| **d** | Кількість тегів і `::pseudo-element` |

| Селектор | (a,b,c,d) | «Вага» |
|---|---|---|
| `style=""` | (1,0,0,0) | 1000 |
| `#wrapper #content` | (0,2,0,0) | 200 |
| `#content .datePosted` | (0,1,1,0) | 110 |
| `div#content` | (0,1,0,1) | 101 |
| `#content` | (0,1,0,0) | 100 |
| `p.comment.datePosted` | (0,0,2,1) | 21 |
| `p.comment` | (0,0,1,1) | 11 |
| `div p` | (0,0,0,2) | 2 |
| `p` | (0,0,0,1) | 1 |

> ⚠️ Числа «1000/100/10/1» — спрощення для навчання. Насправді рівні **не переповнюються**: навіть 11 класів (0,0,11,0) **не переможуть** один id (0,1,0,0).

> ℹ️ Комбінатори (`>`, `+`, `~`, пробіл) та `*` **не додають** специфічності. `:not(.x)` та `:is(.x)` мають специфічність свого аргументу, а `:where()` — завжди 0.

### Стратегія

Робіть **загальні** стилі якомога загальнішими, а **специфічні** — точково. Якщо загальне правило доводиться перекривати багато разів — краще прибрати з нього проблемну властивість і застосувати її явно там, де потрібно.

## 6. Сучасні псевдокласи-«суперсили»

Творче доповнення до лекції — підтримуються всіма сучасними браузерами:

```css
/* :is() — групування без повторів */
:is(header, footer) a:hover { color: gold; }
/* те саме, що: header a:hover, footer a:hover { … } */

/* :where() — як :is(), але зі специфічністю 0 (легко перекрити) */
:where(ul, ol) { padding-left: 1.5rem; }

/* :has() — «батьківський селектор»: картка, що МІСТИТЬ зображення */
.card:has(img) { padding-top: 0; }

/* Поле форми з помилкою підсвічує всю групу */
.field:has(input:invalid) label { color: crimson; }
```

## Резюме

- **Псевдоклас** — додатковий запис до селектора, що визначає стан елемента або його позицію в структурі сторінки.
- **Універсальний селектор** `*` звертається до всіх елементів (або в межах заданої вкладеності).
- **Комбінатори** (пробіл, `>`, `+`, `~`) описують зв'язки між елементами.
- **Пріоритет** визначається каскадом → специфічністю → порядком у коді.

## 🎯 Практичні завдання (з лекції)

Створюйте **без додавання класу кожному елементу** — лише псевдокласами й комбінаторами:

1. **List component** — список з `border-radius: 20px`, фон лише у **парних** пунктів (незалежно від їхньої кількості).
2. **Contacts component** — список контактів із вертикальними розділювачами між пунктами (не після останнього).
3. **Site menu** та **Paginator** — меню й пагінація з посилань, активний пункт виділено, `:hover`-ефекти.
4. **Mini page** — сторінка з меню, контентом із посиланнями та пагінацією. Кнопки меню та пагінації — посилання **без індивідуальних класів**.
