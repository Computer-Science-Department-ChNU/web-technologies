## 1. Властивість margin

**margin** — зовнішній відступ: відстань від рамки елемента до сусідніх елементів. Margin **прозорий** (фон на нього не поширюється) і **не входить** у розмір елемента.

```css
.block {
  margin-top: 50px;
  margin-right: 50px;
  margin-bottom: 50px;
  margin-left: 50px;
}
```

Скорочений запис — так само, як у `padding`, **за годинниковою стрілкою** (Top → Right → Bottom → Left):

| Запис | Означає |
|---|---|
| `margin: 20px;` | усі сторони |
| `margin: 20px 40px;` | верх/низ, право/ліво |
| `margin: 20px 40px 30px;` | верх, право/ліво, низ |
| `margin: 20px 40px 30px 10px;` | верх, право, низ, ліво |

### Від'ємний margin

На відміну від `padding`, `margin` **може бути від'ємним** — елемент «наїжджає» на сусідів або зсувається:

```css
.block { margin-left: -50px; } /* зсув ліворуч на 50px */
```

## 2. margin: auto та центрування

Значення `auto` означає: «браузере, обчисли відступ сам». Для **блочного елемента з заданою шириною** браузер ділить вільне горизонтальне місце порівну між лівим і правим відступом:

```css
.container {
  width: 600px;        /* або max-width */
  margin: 0 auto;      /* ✅ класичне центрування блоку по горизонталі */
}
```

```
|←─── auto ───→|█████ 600px █████|←─── auto ───→|
```

| Хочу | Рішення |
|---|---|
| Відцентрувати **блок** | `width` + `margin: 0 auto` |
| Притиснути блок праворуч | `margin-left: auto` |
| Відцентрувати **текст / inline-вміст** | `text-align: center` для батька |

### Обмеження `margin: auto`

- ❌ Не працює без заданої ширини (блок і так займає 100% — нема чого ділити).
- ❌ Не працює для рядкових (`inline`) елементів.
- ❌ **Не центрує по вертикалі** у звичайному потоці (`margin-top: auto` = 0).
- ✅ Зате у **Flexbox** і **Grid** `margin: auto` центрує в обох напрямках (лекції 11–12).

## 3. Схлопування margin (collapse)

**Вертикальні** відступи **сусідніх** блочних елементів **не додаються** — перемагає **більший**:

```css
.first  { margin-bottom: 70px; }
.second { margin-top: 40px; }
/* Відстань між ними = max(70, 40) = 70px, а НЕ 110px */
```

```
┌─────────┐
│  first  │
└─────────┘
   ↕ 70px  ← не 110!
┌─────────┐
│ second  │
└─────────┘
```

| Напрямок | Відступи сумуються? |
|---|---|
| ↕ Вертикальний (top/bottom) | ❌ **схлопуються** — береться більший |
| ↔ Горизонтальний (left/right) | ✅ додаються |

> 💡 Щоб не плутатися, багато команд домовляються задавати вертикальні відступи **лише в одному напрямку** — наприклад, тільки `margin-bottom`.

## 4. Провалювання margin

Якщо у **першого (чи останнього) дочірнього** елемента є `margin-top` (`margin-bottom`), а в батька **немає** `padding`, `border` чи іншого «бар'єра» — margin дитини **«провалюється»** назовні й відсуває **батька**:

```html
<header class="header">
  <h1>Заголовок</h1>  <!-- у h1 браузер за замовчуванням має margin -->
</header>
```

```css
.header { background: lightgreen; }
/* Очікування: зелений фон починається від самого верху сторінки,
   а h1 відступає всередині.
   Реальність: відступ h1 «вийшов» назовні — над зеленим фоном з'явилась біла смуга 😱 */
```

### Як виправити (будь-який варіант)

```css
.header { padding-top: 1px; }          /* бар'єр-padding */
.header { border-top: 1px solid transparent; } /* бар'єр-border */
.header { display: flow-root; }        /* ✅ сучасний «чистий» спосіб — новий контекст форматування */
.header { overflow: hidden; }          /* старий спосіб (може обрізати вміст) */
```

Також провалювання **не відбувається**, якщо батько — flex- або grid-контейнер.

> 📄 Приклад: [02_collapse.html](examples/02_collapse.html)

## 5. margin у рядкових та inline-block елементів

| `display` | Горизонтальний margin | Вертикальний margin | `width`/`height` | Новий рядок |
|---|---|---|---|---|
| `block` | ✅ | ✅ | ✅ | ✅ займає весь рядок |
| `inline` | ✅ | ❌ ігнорується | ❌ | ❌ стоїть у рядку |
| `inline-block` | ✅ | ✅ | ✅ | ❌ стоїть у рядку |

**`inline-block`** — «гібрид»: зовні поводиться як **рядковий** (стоїть у ряд з іншими, вирівнюється по `text-align` батька), всередині — як **блочний** (розміри, усі відступи).

```css
.tag {
  display: inline-block;
  padding: 4px 12px;
  margin: 4px;
  border-radius: 12px;
  background: lavender;
}
```

> ⚠️ `margin: auto` для `inline-block` **не центрує** — для цього використовуйте `text-align: center` на батькові.

## 6. Проміжок між inline-block елементами

Між `inline-block` елементами з'являється **«загадковий» проміжок ~4px**. Причина — **переноси рядків і пробіли в HTML-коді**: для inline-елементів це звичайний пробіл у тексті!

```html
<div class="block">1</div>   ← цей перенос рядка = пробіл
<div class="block">2</div>
```

### Як прибрати

1. Написати теги без пробілів між ними (`</div><div>`) — некрасиво.
2. `font-size: 0` для батька й повернути розмір дітям — хак.
3. ✅ Використати **Flexbox** (`display: flex` для батька) — сучасне рішення, пробіли ігноруються.

> 📄 Приклад: [05_space.html](examples/05_space.html)

## 7. border-radius

Заокруглення кутів елемента (фон, рамка й тінь заокруглюються разом).

```css
.block { border-radius: 10px; }        /* усі кути */
.block { border-radius: 10px 30px; }   /* ↖↘ = 10px, ↗↙ = 30px */
.block { border-radius: 10px 20px 30px 40px; } /* ↖ ↗ ↘ ↙ — за годинниковою */

/* Окремі кути */
.block {
  border-top-left-radius: 10px;
  border-top-right-radius: 30px;
  border-bottom-right-radius: 25%;
  border-bottom-left-radius: 2px;
}
```

### Корисні рецепти

```css
.avatar { width: 100px; height: 100px; border-radius: 50%; }  /* ⚪ коло (для квадрата) */
.pill   { border-radius: 9999px; }                            /* 💊 «пігулка»-кнопка */
.card   { border-radius: 12px; overflow: hidden; }            /* картинка всередині теж заокруглиться */
```

> 💡 `border-radius: 50%` на **прямокутнику** дасть **еліпс**, а не коло.

> 📄 Приклади: [06_border-radius.html](examples/06_border-radius.html), [06.1_border-radius.html](examples/06.1_border-radius.html)

## Резюме

- **margin** — відстань від елемента до сусідів з усіх чотирьох сторін; може бути від'ємним.
- **Схлопування** — вертикальні margin сусідів не додаються, перемагає більший.
- **Провалювання** — margin першої/останньої дитини виходить за межі батька без padding/border.
- `margin: 0 auto` центрує блок із заданою шириною по горизонталі.
- **inline-block** поєднує рядкову (стоїть у рядку) і блокову (розміри, відступи) поведінку.
