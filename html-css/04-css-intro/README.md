## 1. Що таке CSS

**CSS** (Cascading Style Sheets, каскадні таблиці стилів) — мова, що описує **зовнішній вигляд** HTML-елементів: кольори, шрифти, розміри, відступи, розташування, анімації.

> HTML відповідає на питання **«що це?»**, CSS — на питання **«як це виглядає?»**.

### Типи стилів (джерела)

| Тип | Хто задає | Приклад |
|---|---|---|
| **Браузерні** (user agent) | Браузер за замовчуванням | `h1` жирний і великий, у `body` є `margin: 8px`, посилання сині та підкреслені |
| **Авторські** | Розробник сайту | Ваші `.css`-файли |
| **Користувацькі** | Користувач у налаштуваннях браузера | Збільшений шрифт, примусова висока контрастність |

> 💡 Саме через різні браузерні стилі в різних браузерах розробники використовують **reset.css** або **normalize.css** — вони «вирівнюють» стартові стилі.

## 2. Синтаксис CSS

```css
селектор {
  властивість: значення;
  властивість: значення;
}
```

```css
h1 {
  color: darkblue;      /* колір тексту */
  font-size: 32px;      /* розмір шрифту */
}
```

| Частина | Роль |
|---|---|
| **Селектор** | *Кого* стилізуємо (`h1`, `.card`, `#logo`) |
| **Фігурні дужки `{ }`** | Блок оголошень |
| **Властивість** | *Який аспект* змінюємо (`color`) |
| **Двокрапка `:`** | Відділяє властивість від значення |
| **Значення** | *Як* саме (`darkblue`) |
| **Крапка з комою `;`** | Завершує оголошення |

- Пара `властивість: значення;` — це **оголошення** (declaration).
- Селектор + блок оголошень — це **правило** (rule).
- Коментарі в CSS: `/* коментар */` (лише такий формат; `//` у CSS **не працює**).
- Один блок стилів можна застосувати до кількох селекторів через кому: `h1, h2, h3 { … }`.

> ⚠️ **Типова помилка:** забута `;` в останньому рядку ще пробачається, але в середині блоку «ламає» наступне оголошення. Ставте `;` завжди.

## 3. Універсальні (глобальні) атрибути

Атрибути, які можна застосувати до **будь-якого** HTML-елемента:

| Атрибут | Призначення |
|---|---|
| `class` | Одне або кілька імен класів через пробіл — головний «гачок» для CSS |
| `id` | Унікальний ідентифікатор елемента (один на документ) |
| `style` | Вбудовані (inline) стилі |
| `title` | Спливаюча підказка |
| `lang` | Мова вмісту |
| `hidden` | Приховати елемент |
| `tabindex` | Участь у клавіатурній навігації |
| `data-*` | Власні дані для JS/CSS (`data-id="42"`) |

```html
<h1 class="title main-title" id="top" title="Підказка">Заголовок</h1>
```

> 📄 Приклад: [01_universal_attrs.html](examples/01_universal_attrs.html)

## 4. Способи підключення стилів

### 1) Inline — атрибут `style`

```html
<p style="color: blue; background-color: yellow;">Текст</p>
```

### 2) Внутрішні стилі — тег `<style>` в `<head>`

```html
<head>
  <style>
    p { color: blue; }
  </style>
</head>
```

### 3) Зовнішній файл — тег `<link>` в `<head>` ✅

```html
<head>
  <link rel="stylesheet" href="css/style.css">
</head>
```

| Спосіб | Переваги | Недоліки |
|---|---|---|
| **Inline** | Швидко для тесту; найвищий пріоритет | Змішує структуру й оформлення; неможливо перевикористати; важко підтримувати |
| **`<style>`** | Все в одному файлі | Стилі не діляться між сторінками |
| **Зовнішній `.css`** ✅ | Один файл на весь сайт; кешується браузером; чистий HTML | Додатковий HTTP-запит |

> 📌 **Рекомендація:** використовуйте **зовнішні файли**. Inline-стилі — якомога рідше.

> 📄 Приклади: [02_inline_styles.html](examples/02_inline_styles.html), [03_add_styles.html](examples/03_add_styles.html) + [03_style.css](examples/03_style.css)

## 5. Базові селектори

| Селектор | Синтаксис | Кого вибирає | Вага |
|---|---|---|---|
| Універсальний | `*` | Усі елементи | 0 |
| За тегом (тип) | `p` | Усі `<p>` | 1 |
| За класом | `.card` | Усі елементи з `class="card"` | 10 |
| За id | `#header` | Елемент з `id="header"` | 100 |
| За атрибутом | `[type="email"]` | Елементи з таким атрибутом | 10 |
| Група | `h1, h2, .title` | Кожен із перелічених | — |

```css
#identifier { background: red; }   /* id */
.name-class { background: blue; }  /* клас */
p           { background: gold; }  /* тег */
```

### Правила іменування класів та id

- ✅ Можна: латинські літери, цифри, `-`, `_`: `card`, `main-menu`, `btn_primary`, `item2`.
- ❌ Не можна починати з цифри: `#1identifier` — **не працює**.
- ❌ Без пробілів (пробіл у `class` розділяє *різні* класи).
- 💡 Рекомендований стиль — **kebab-case**: `.product-card`, `.main-nav`.
- 💡 Називайте за **призначенням**, а не виглядом: `.error-message` ✅, `.red-text` ❌.

### Клас чи id?

| | `class` | `id` |
|---|---|---|
| Кількість на сторінці | Скільки завгодно | **Один** унікальний |
| Класів у елемента | Багато: `class="btn btn-large"` | Лише один id |
| Для стилізації | ✅ Основний інструмент | ⚠️ Уникайте — занадто висока вага |
| Інше використання | — | Якорі (`#contacts`), зв'язок `label for`, JS |

## 6. Каскад і пріоритет

Коли до одного елемента застосовано **кілька конфліктуючих правил**, браузер обирає переможця за трьома критеріями — по черзі:

```
1. Важливість (!important)    ──►  якщо рівно  ──►
2. Специфічність (вага)        ──►  якщо рівно  ──►
3. Порядок у коді (хто нижче — той переміг)
```

### Специфічність (вага селектора)

| Джерело | Вага |
|---|---|
| Атрибут `style="…"` | **1000** |
| `#id` | **100** |
| `.class`, `[attr]`, `:pseudo-class` | **10** |
| `tag`, `::pseudo-element` | **1** |
| `*` | 0 |

```html
<p class="paragraph" id="alert" style="background: red;">Текст</p>
```

```css
#alert     { background: green; } /* 100 */
.paragraph { background: blue; }  /* 10 */
p          { background: gold; }  /* 1 */
/* Переможе inline style (1000) → фон червоний */
```

### Однакова вага → перемагає останнє правило

```css
.paragraph { color: green; background: aqua; }
.paragraph { background: blue; }   /* ← перекриває background, color лишається green */
.message   { background: gold; }   /* ← та сама вага (10), але нижче → переміг */
```

```html
<!-- Порядок класів в атрибуті НЕ має значення! Важить лише порядок правил у CSS -->
<p class="paragraph message">…</p>  <!-- фон gold -->
<p class="message paragraph">…</p>  <!-- теж gold -->
```

### `!important`

```css
p { background: gold !important; } /* перебиває навіть id та inline */
```

> ⚠️ `!important` — «ядерна зброя». Він ламає природний каскад, і щоб перебити його, доводиться ставити ще один `!important`. Використовуйте лише в крайніх випадках (наприклад, утилітарні класи або перекриття чужої бібліотеки).

> 📄 Приклади: [05_priority..html](examples/05_priority..html), [05.1_priority.html](examples/05.1_priority.html), [05.2_priority..html](examples/05.2_priority..html)

### Що означає «каскадні»?

Стилі «стікають каскадом»: з різних джерел (браузер → автор → inline), з різних правил, від батьків до дітей (успадкування — тема наступної лекції). Підсумковий вигляд елемента — результат «злиття» всіх правил за наведеними вище законами.

## 7. Інструменти розробника

Натисніть `F12` (або ПКМ → «Переглянути код» / «Inspect»):

- вкладка **Elements** → панель **Styles** показує всі правила, що застосовані до елемента;
- **закреслені** властивості — ті, що програли в каскаді;
- можна змінювати значення «наживо» й одразу бачити результат;
- панель **Computed** показує підсумкові значення.

> 🧪 Наведіть курсор на селектор у панелі Styles — Chrome покаже його специфічність.

## Резюме

- **Універсальні атрибути** — атрибути, які застосовуються до всіх HTML-елементів (`class`, `id`, `style`, `title`…).
- **Підключення CSS** — inline, `<style>` або зовнішній файл через `<link>` (рекомендовано).
- **Селектори** зв'язують CSS-правила з HTML-елементами.
- **Пріоритет** визначає, яке правило перемагає в конфлікті: `!important` → специфічність → порядок.
- **Каскад** — правила з однаковою специфічністю: перемагає останнє.

## 🎯 Практичне завдання

1. Пройдіть перші 15 рівнів гри [CSS Diner](https://flukeout.github.io/).
2. Створіть сторінку з трьома абзацами та підключіть стилі **трьома способами одночасно** так, щоб кожен абзац мав інший колір фону. Поясніть, чому переміг саме цей стиль.
3. «Детектив специфічності»: без запуску визначте колір тексту та перевірте в браузері.

```html
<div id="box" class="card">
  <p class="text important">Який я колір?</p>
</div>
```

```css
#box p            { color: red; }
.card .text       { color: green; }
.text.important   { color: blue; }
div p             { color: orange; }
```
