## 1. Нормальний потік документа

За замовчуванням елементи розташовуються **в потоці**: блочні — один під одним, рядкові — один за одним у рядку. Кожен елемент «знає» про сусідів і штовхає їх.

**Позиціювання** дозволяє змінити цю поведінку: зсунути елемент або взагалі **вивести з потоку**, щоб він не займав місця й не впливав на сусідів.

---

## 2. Властивість position — огляд

| Значення | У потоці? | Відносно чого зсувається (`top/right/bottom/left`) | Типове застосування |
|---|---|---|---|
| `static` (за замовч.) | ✅ | Зсув не працює | Звичайні елементи |
| `relative` | ✅ (місце зберігається) | Своєї **початкової позиції** | Батько для `absolute`, невеликі зсуви |
| `absolute` | ❌ | Найближчого **позиційованого предка** | Бейджі, тултіпи, випадаючі меню, іконки |
| `fixed` | ❌ | **Вікна браузера (viewport)** | Кнопка «вгору», модальні вікна, чат-віджет |
| `sticky` | ✅ | Поводиться як `relative`, доки не досягне порогу, далі «прилипає» в межах батька | Липка шапка, заголовки таблиць, сайдбар |

Зсув задається властивостями **`top`, `right`, `bottom`, `left`** (або скорочено **`inset`**: `inset: 0` = усі чотири по 0).

> 💡 «Позиційований елемент» — будь-який з `position`, відмінним від `static`.

## 3. static

Значення за замовчуванням. Елемент у звичайному потоці; `top/left/…` та `z-index` **не працюють**.

> 📄 Приклад: [01-static.html](examples/01-static.html)

## 4. relative

```css
.box {
  position: relative;
  top: 20px;    /* зсув ВНИЗ від початкової позиції */
  left: 30px;   /* зсув ВПРАВО */
}
```

- Елемент зсувається **візуально**, але **його місце в потоці лишається зарезервованим** — сусіди не рухаються.
- Через зсув елемент може налізати на сусідів.

> 🔑 **Головне застосування `relative`** — не зсуви, а створення **точки відліку** для дочірніх `absolute`-елементів (без жодних `top/left`).

> 📄 Приклад: [02-relative.html](examples/02-relative.html)

## 5. absolute

```css
.card  { position: relative; }     /* точка відліку */
.badge {
  position: absolute;
  top: 10px;
  right: 10px;                      /* у правому верхньому куті КАРТКИ */
}
```

- Елемент **випадає з потоку**: не займає місця, сусіди його «не бачать».
- Позиціюється відносно **найближчого позиційованого предка** (`relative`, `absolute`, `fixed`, `sticky`). Якщо такого немає — відносно **початкового блоку** (по суті, сторінки).
- Ширина стискається **до вмісту** (як у `inline-block`).
- Можна розтягнути між сторонами: `top: 0; bottom: 0; left: 0; right: 0;` (або `inset: 0`) — займе весь батьківський блок.

### Схема «батько relative + дитина absolute»

```
┌─── .card (relative) ─────────────┐
│                       ┌───────┐  │
│                       │ badge │  │ ← absolute; top: 10px; right: 10px
│                       └───────┘  │
│   Вміст картки                   │
└──────────────────────────────────┘
```

> ⚠️ **Типова помилка:** забули `position: relative` на батькові → `absolute`-елемент «відлітає» в куток сторінки.

> 📄 Приклади: [03-1-absolute.html](examples/03-1-absolute.html), [03-2-absolute.html](examples/03-2-absolute.html), [03-3-absolute.html](examples/03-3-absolute.html)

## 6. fixed

```css
.to-top {
  position: fixed;
  right: 20px;
  bottom: 20px;     /* завжди в правому нижньому куті екрана */
}
```

- Випадає з потоку; позиціюється відносно **вікна браузера** й **не рухається при прокручуванні**.
- ⚠️ Фіксована шапка перекриває початок вмісту — додайте `padding-top` для `body`, що дорівнює висоті шапки.
- ⚠️ Якщо в предка є `transform`, `filter` або `perspective`, `fixed` поводиться як `absolute` відносно цього предка.

> 📄 Приклад: [04-fixed.html](examples/04-fixed.html)

## 7. sticky

```css
.header {
  position: sticky;
  top: 0;            /* ⚠️ обов'язково вказати поріг! */
}
```

- Поки поріг не досягнуто — елемент у потоці, як `relative`.
- Коли при прокручуванні елемент доходить до `top: 0` — він «прилипає».
- Прилипає **лише в межах свого батька**: коли батько закінчується — елемент їде далі разом із ним.

### fixed vs sticky

| | `fixed` | `sticky` |
|---|---|---|
| Займає місце в потоці | ❌ | ✅ |
| Відносно чого | Вікно браузера завжди | Найближчий предок з прокручуванням, у межах батька |
| Коли використовувати | Завжди видимі елементи: навбар, кнопка «вгору», чат | Тимчасово закріплені: шапка розділу, заголовок таблиці, сайдбар |

### Чому sticky «не працює»? 🕵️

1. Не вказано `top` (або `bottom`).
2. Батько такої ж висоти, як і сам елемент — немає куди «липнути».
3. У когось із предків `overflow: hidden/auto/scroll`.

> 📄 Приклади: [05-1-sticky.html](examples/05-1-sticky.html), [05-2-sticky.html](examples/05-2-sticky.html), [05-3-sticky-header.html](examples/05-3-sticky-header.html), [05-4-sticky-sidebar.html](examples/05-4-sticky-sidebar.html), [05-5-sticky-table-header.html](examples/05-5-sticky-table-header.html)

## 8. z-index і контекст накладання

Позиційовані елементи можуть перекривати один одного. **`z-index`** задає порядок шарів уздовж уявної осі Z, «перпендикулярної екрану»: **більше значення — ближче до користувача**.

```css
.modal   { position: fixed; z-index: 100; }
.overlay { position: fixed; z-index: 99; }
```

- Працює лише для **позиційованих** елементів (а також для flex- і grid-елементів).
- Без `z-index` пізніші в HTML елементи малюються поверх ранніх.
- Може бути від'ємним: `z-index: -1` — під батьківським вмістом.

### Контекст накладання (stacking context) — головна пастка

Елемент з `position` + `z-index` (а також з `opacity < 1`, `transform` тощо) створює **власний контекст накладання**. Діти «замкнені» всередині нього: `z-index: 9999` дитини не підніме її над сусідом **батька**, якщо сам батько нижче.

```
.parent-1 (z-index: 1)          .parent-2 (z-index: 2)
   └── .child (z-index: 9999)      ← все одно ПІД .parent-2 😱
```

> 💡 Тримайте шкалу `z-index` впорядкованою (наприклад, 10 — дропдаун, 100 — шапка, 1000 — модалка) замість гонки `9999` vs `99999`.

## 9. overflow і text-overflow

### overflow

| Значення | Поведінка |
|---|---|
| `visible` (за замовч.) | Вміст, що не вміщається, видно за межами блоку |
| `hidden` | Обрізати, без прокрутки |
| `scroll` | Обрізати, смуги прокрутки **завжди** (стабільний макет без «стрибків») |
| `auto` | Смуги прокрутки — **лише за потреби** |

### Три крапки в кінці рядка…

```css
.title {
  white-space: nowrap;      /* 1. не переносити */
  overflow: hidden;         /* 2. обрізати */
  text-overflow: ellipsis;  /* 3. показати «…» */
}
```

Усі три властивості **обов'язкові разом** (і блок має мати обмежену ширину).

> 📄 Приклади: [07-overflow.html](examples/07-overflow.html), [08-text-overflow.html](examples/08-text-overflow.html)

## 10. visibility

```css
visibility: visible | hidden | collapse;
```

- `hidden` — елемент невидимий, але **місце за ним зберігається** («гра в хованки» 🙈).
- `collapse` — для рядків/стовпців таблиці: прибирає їх, як `display: none`.
- Щоб показувати різні елементи в одному місці — використовуйте `position: absolute` або `display`.

> 📄 Приклад: [09-visibility.html](examples/09-visibility.html)

## 11. Рецепти

### Центрування absolute-елемента

```css
.parent { position: relative; }
.center {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

### Тултіп

```css
.tooltip { position: relative; }
.tooltip__text {
  position: absolute;
  bottom: 100%;               /* над елементом */
  left: 50%;
  transform: translateX(-50%);
  visibility: hidden;
  opacity: 0;
  transition: opacity .2s;
}
.tooltip:hover .tooltip__text,
.tooltip:focus-within .tooltip__text {
  visibility: visible;
  opacity: 1;
}
```

### Модальне вікно з оверлеєм

```css
.overlay {
  position: fixed;
  inset: 0;                      /* на весь екран */
  background: rgb(0 0 0 / 60%);
  z-index: 1000;
}
```

> ⛔ **Нагадування (з презентації):** не використовуйте `position: absolute` для побудови **всього макета** сторінки. Для розкладки є Flexbox і Grid; позиціювання — для «точкових» елементів поверх потоку.

## 🎯 Практичні завдання (з лекції)

1. **Sub menu** — випадаюче підменю при наведенні (`relative` + `absolute`).
2. **Price card** — картка з бейджем «Популярне» в куті.
3. **Tooltips** — підказки над кнопками (`relative` + `absolute`).
4. **Sticky header** — шапка, що прилипає при прокручуванні.
5. **Sticky sidebar** — бічна панель, що прилипає в межах контенту.
6. **[Popup](task-popup/task.adoc)** — меню застосунків (як у Google) **без JavaScript**: показ/приховування, прокрутка при великій кількості іконок, стани `:hover` та `:focus`.
